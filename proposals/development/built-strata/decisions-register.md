# Built Strata Profile — Decisions Register

Pre-read for the Built Strata profile presentation. Item numbers match [`built-strata-questions.md`](built-strata-questions.md) in the profile repository; items [16](#item-16)–[18](#item-18) are added from the scope note and use case.

Each item has a **recommendation** from Surround. We are asking Landgate to **accept, amend, or assign an owner and date**.

Landgate responded on 2026-10-27 (working notes, Rev A; issue [#43](https://github.com/surroundaustralia/3d-csdm-profile-wa/issues/43)). Their decisions are recorded in the Decision column, and the new items they raised are in [section F](#f-items-raised-by-landgate-2026-10-27). The analysis and plan are in [`landgate-response-analysis.md`](landgate-response-analysis.md).

## A. Policy (Landgate)

| #  | Question                                                                                                  | Recommendation                                                                                                   | Decision / Owner / Due |
|----|-----------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------|------------------------|
| <a id="item-1"></a>1  | Will WA ever treat submitted 3D geometry as the authoritative legal boundary (`legal-3d`), or only as derived from the plan wording (`derived-from-legal-description`)? | Encode as `derived-from-legal-description` now; the model already supports moving to `legal-3d` with no structural change.                       | Accepted (Landgate, 2026-10-27): `derived-from-legal-description`. Built form remains the survey monument for built strata; Landgate does not intend to change this legal construct. |
| <a id="item-13"></a>13 | How should an exclusive-use area that stays common property be represented?                             | Not part of the lot's `AggregateSolid`; represent as an interest or secondary spatial object where legally required. | Amended (Landgate, 2026-10-27): a `SecondaryParcel` with a new [`wa-secondary-parcel-purpose`](https://linked.data.gov.au/def/csdm/wa-secondary-parcel-purpose) term for by-law exclusive use (label to be settled); appellation `[Lot]-[Label]-[Doc]`. Restricted use and leases follow the same pattern ([item 24](#item-24)). Surround to request terms through the `sa-icsm-vocabs` uplift owner. |
| <a id="item-16"></a>16 | Should common property be captured only for display/interpretation, or ever as a queryable cadastral volume? | Display/interpretation only, consistent with current Landgate practice; but record explicitly that residual space is common property. | Accepted (Landgate, 2026-10-27): common-property elements stay parcel elements so they can be labelled (car bay, stairs, void, common property), with a display state; existing [`wa-parcel-state:abuttal`](https://linked.data.gov.au/def/csdm/wa-parcel-state/abuttal) proposed. Surround to confirm whether a purpose term is also needed. |
| <a id="item-15"></a>15 | What does `area` mean for a multipart strata lot (habitable only, sum of all components, or projected footprint)? | No recommendation yet; needs a Landgate definition. Component areas can be derived from geometry whichever is chosen. | Decided (Landgate, 2026-10-27): `area` is the legal 2D extent of each component; a 3D submission shows component areas, and the lot total need not be stated. Related: building extents and clearances ([item 22](#item-22)). |
